# Local inventory

Mode: Operate. One route, `/`, for finding and opening the correct local service.
The confirmed brief calls for a very small, read-only utility.

## Direction contract

**THESIS:** An immediately searchable directory of running services. The inventory
itself is the main surface; no overview charts or decorative metric cards.

**OWN-WORLD:** Restrained teal actions, slate text and pale surfaces, with system
sans for labels and tabular monospace only for ports and paths. Honor the user's
system light/dark preference. The developer works alongside an editor, so density
and legibility matter more than an expressive display face.

**STORY:** Find a port, identify its project and branch, open a recognized web
service. Unknown information remains explicit.

**FIRST VIEWPORT:** Compact product header, title and freshness, search and refresh
controls, then aligned service rows. Port links are the strongest actions.
Rows become vertically grouped records on a narrow viewport. Pausing refresh
holds the inventory still for inspection.

**FORM:** A compact indexed directory, translated into ordinary web controls.
The user's explicit simplicity requirement constrains the design.

**FINISH:** unreviewed and undocumented is unfinished; this build ends with the
finish review, the verdict, DESIGN.md, and every shipping raster carrying its
provenance.
